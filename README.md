# DeFiPulsePro

An event-driven, smart DeFi market intelligence system that processes real-time data and automates position sizing.

With DeFiPulsePro, you get a lightweight tool that stays out of your way.

**What you get**

- An event-driven, smart DeFi market
- intelligence system that processes real-time
- data and automates position sizing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/DeFiPulsePro.git`
2. `cd DeFiPulsePro`
3. Install in editable mode: `pip install -e .`

## Configuration

DeFiPulsePro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
